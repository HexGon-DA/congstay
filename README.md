- **Màu nền tổng thể:** Trắng ngà / Giấy báo cũ (`#F4EEDD`)
- **Màu thanh Header, Footer & Tiêu đề:** Xanh bộ đội (`#2B3D2E`)
- **Màu khối thẻ (Card), trích dẫn:** Vàng vôi tường cổ (`#DCAE42`)
- **Màu nút bấm chính (CTA Button):** Đỏ tem phiếu (`#A8322D`)
- **Phông chữ:**
  - Tiêu đề (Headings): *Be Vietnam Pro Bold / Montserrat ExtraBold / Courier Prime*
  - Nội dung (Body text): *Inter / Roboto*
- **Logo Cộng Stay:** Ngôi sao vàng viền tròn kết hợp khung cửa sổ gỗ retro trên nền xanh bộ đội (`/public/cong-stay-logo.svg`).

## 3. Hướng Dẫn Khởi Chạy

### Chế độ phát triển (Development)
```bash
npm install
npm run dev
```
Mở trình duyệt tại đường dẫn `http://localhost:5173`.

### Bản dựng phân phối (Production Build)
```bash
npm run build
```
Thư mục sản phẩm hoàn chỉnh nằm tại `dist/` (có thể chạy `npm run preview` hoặc mở trực tiếp `dist/index.html`).
